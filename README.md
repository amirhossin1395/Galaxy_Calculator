# 🌌 کهکشان حساب (Galaxy Calculator)

**توسعه‌دهنده:** امیرحسین حاجی مرادخانی  
**نسخه:** 1.00  
تمامی حقوق محفوظ است  

---

## 📱 معرفی

**کهکشان حساب** یک ماشین‌حساب حرفه‌ای و کامل است که با هدف ارائه‌ی بهترین تجربه‌ی محاسباتی طراحی شده است. این ماشین‌حساب از ماشین‌حساب‌های موبایل‌های معروف مانند سامسونگ، اپل، شیائومی و هواوی بهتر است و امکانات پیشرفته‌ای را در اختیار کاربران قرار می‌دهد.

---

## ✨ ویژگی‌ها

### 🧮 حالت‌های محاسباتی
- **حالت پایه:** جمع، تفریق، ضرب، تقسیم، درصد، تغییر علامت
- **حالت علمی:** سینوس، کسینوس، تانژانت، لگاریتم، لگاریتم طبیعی، رادیکال، توان ۲، توان ۳، فاکتوریل، توان دلخواه، پرانتز

### 🔄 تبدیل‌های پیشرفته
- حجم (لیتر، میلی‌لیتر، متر مکعب، گالن)
- مساحت (متر مربع، کیلومتر مربع، هکتار، فوت مربع)
- وزن (کیلوگرم، گرم، پوند، اونس)
- طول (متر، کیلومتر، مایل، فوت، اینچ)
- سرعت (متر بر ثانیه، کیلومتر بر ساعت، مایل بر ساعت، گره)
- فشار (پاسکال، بار، اتمسفر، psi)
- انرژی (ژول، کالری، وات ساعت، الکترون ولت)
- دما (سلسیوس، فارنهایت، کلوین)

### 📜 تاریخچه هوشمند
- ذخیره‌سازی تا ۲۰۰۰ عملیات
- قابلیت جستجو در تاریخچه
- نمایش عبارت و نتیجه

### 🌍 پشتیبانی از ۳ زبان
- فارسی
- انگلیسی
- عربی

### 🎨 تم‌های گرافیکی
- تم تاریک
- تم روشن
- تم دستگاه (Device Dark)

### ⌨️ پشتیبانی کامل از ورودی‌ها
- کیبورد (اعداد، عملگرها، Enter، Backspace، Escape)
- موس
- لمس (لمسی)

### 📋 امکانات دیگر
- کپی نتیجه با یک کلیک
- کاملاً آفلاین (بدون نیاز به اینترنت)
- بهینه برای موبایل، تبلت و لپ‌تاپ

---


## 🚀 نحوه‌ی استفاده

1. فایل را را در مرورگر خود باز کنید.
2. زبان مورد نظر خود را انتخاب کنید (فارسی، انگلیسی، عربی).
3. از تب‌های بالا برای تغییر حالت استفاده کنید:
   - **پایه:** محاسبات روزمره
   - **علمی:** محاسبات پیشرفته
   - **تبدیل:** تبدیل واحدها
   - **راهنما:** راهنمای کامل
   - **درباره:** اطلاعات پروژه
4. برای جستجو در تاریخچه، از کادر جستجو استفاده کنید.
5. برای کپی نتیجه، روی دکمه‌ی کپی کلیک کنید.

## ⌨️ کلیدهای میانبر کیبورد

| کلید | عملکرد |
|------|--------|
| 0-9 | اعداد |
| + - * / | عملگرها |
| Enter یا = | محاسبه |
| Backspace | حذف آخرین کاراکتر |
| Escape | پاک کردن همه |
| % | درصد |
| ( ) | پرانتز |
